# test — 내부평가 성과관리

폐쇄망 서버에서 사용할 직원 계정·근무지·담당지표 관리 모듈의 초기 구현입니다.
Python 3.11 이상과 표준 라이브러리만 사용하며 외부 API, CDN, 패키지 설치가 필요하지 않습니다.

## 실행

```bash
python app.py
```

브라우저에서 http://127.0.0.1:8080 에 접속합니다. Windows에서는 `py app.py`를 사용할 수 있습니다.

**사용자의 공개 업로드 승인에 따라 실제 부서 55개·성과지표 165개를 `catalog.json`에 포함했습니다.** 제공된 표준양식에서 추출한 기준자료입니다. 원본 PDF·엑셀과 계정 DB는 포함하지 않습니다.
`catalog.json`이 없으면 `catalog.example.json`의 가상 예시 데이터를 읽고 화면에 예시 데이터임을 표시합니다.
조직 표시명과 원문 적용부서명이 다른 경우 `indicator_department`로 연결합니다.
예시에서 실제 기준자료로 전환할 때는 예시로 생성한 계정 DB를 분리하여 운영해야 합니다.

## 제공 기능

- 사번·비밀번호 회원가입, 사번 앞자리 0 보존 및 중복 차단
- 근무지별 담당지표 복수 선택과 서버 DB 저장
- 로그인 시 저장한 근무지·담당지표 복원
- 첫 화면에서 근무지 변경과 담당지표 수정
- 근무지 변경 시 지표 재선택, 변경 전후 설정·변경시각 보존
- 비밀번호 scrypt 해시, 서버 세션, CSRF 검증, 동시수정 감지
- 로그아웃·8시간 세션 만료, 로그인 실패 횟수 제한

선택한 담당지표는 본인의 업무 설정입니다. 관리자·평가자 권한을 부여하지 않습니다.

## 내부망 실행

사내 인증기관에서 발급한 인증서와 키를 사용합니다.

```bash
python app.py --host 0.0.0.0 --port 8443 --cert server.crt --key server.key
```

직원은 인증서 이름과 일치하는 내부 DNS 주소로 접속합니다. 내부 서버 방화벽과 서비스 자동시작은 운영환경에 맞게 설정합니다.
HTTP 기본 실행은 로컬 확인용입니다. 직원이 접속하는 내부망 환경은 HTTPS로 구성합니다.

계정·설정·변경 이력은 `data/performance.sqlite3`에 저장됩니다. 서버를 종료하고 data 폴더를 백업하거나 운영 중 SQLite backup API를 사용합니다.
비밀번호나 세션 원문은 저장하지 않습니다. 서버 관리자는 DB와 인증서 개인키 접근권한을 제한해야 합니다.

## 테스트

```bash
python -m unittest -v test_app
```

회원가입부터 재로그인 후 복원, 근무지 변경 이력, 서버 검증, 계정별 접근 분리, 만료 세션, 로그인 시도 제한을 검증합니다.
브라우저 화면 확인, 실제 내부망 배포 및 부하검증은 아직 수행하지 않았습니다.

## 후속 개발 범위

직원 여부 확인을 위한 인사명부 대조·가입 승인, 비밀번호 재설정, 계정 비활성화,
평가 권한, 실적 입력·증빙·점수 계산은 아직 포함하지 않았습니다.
사번을 직접 입력하는 가입 방식이므로 실제 직원 운영 전 계정 확인 절차를 구성해야 합니다.

향후 실적 데이터에는 작성 당시 부서와 지표·양식 버전을 별도로 저장해야 하며,
인사이동 시 과거 실적의 소속이 바뀌지 않도록 설계합니다.
